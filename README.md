# Gunters forge - KU Design Challenge

## Project Overview and Purpose
Gunters Forge is a mobile-friendly online blacksmith storefront and an order-management platform created for the KU Design Challenge. Custmers can browse Gunters products, place orders, track the progress of their orders. The Blacksmith can manage order status and monitor inventory.

## Features
1. Storefront Homepage
- Displays four product cards with images and prices.
- Provides a separate page with details for each product card.
- Includes navigation between the main website pages.
- Uses custom medieval artwork and illustrations in the background and buttons.

2. Shopping Cart
- Allows customers to add products to their cart.
- Lets customers change quantities or remove items.
- Automatically calculates the total cost of the cart.
- Prevents customers from checking out with an empty cart.

3. Checkout
- Collects the customer's name and displays an order summary.
- Checks material availability before processing orders.
- Generates a unique order number for each purchase.
- Displays a confirmation after an order is placed.

4. Order Tracking
- Allows customers to search for order by name or order number.
- Displays order details and current order status.
- Shows an order's position in the queue.
- Updates customers when orders are ready or completed.

5. Gunter's Access
- Provides a password protected access to the management dashboard.
- Displays customer orders and their details.
- Allows Gunter to update order statuses and manage the queue.
- Provides an option to log out of the dashboard.

6. Inventory Managment
- Tracks five crafting materials and their stock levels.
- Allows Gunter to update and save inventory quantities.
- Displays warnings when material supplies are low.
- Checks and deducts materials when forging begins.

7. Technical Features
- Uses HTML, CSS, and JavaScript to run the website.
- Adapts the layout to different screen sizes.
- Saves cart, order, and inventory date in the browser.
- Automatically updates prices, order details, and inventory displays.

## How to use the app
### Customer Features
- Browse products and view their descriptions, images, and prices.
- Select product quantities and add items to the shopping cart.
- Review the cart, enter a name, and place an order.
- Track orders by customer name or order number.
- View order details, status, and position in the queue.

### Gunter's Features
- Log in to Gunter's Access using the password (forgekeeper), which is only available to Gunter.
- View customer orders and manage the order queue.
- Update order statuses as products move through the forging process.
- Monitor inventory levels and receive low stock warnings.
- Update material quantities and manage supplies used for orders.
