# Gunters forge - KU Design Challenge

## Project Overview and Purpose
Gunnters Forge is a mobile-friendly online blacksmith storefront and an order-management platform created for the KU Design Challenge. Coustmers can browse Gunters products, place orders, track the progress of their orders. The Blacksmith can manage order status and monitar inventory.
